# share-a-bean

Working name: Share-a-Bean. A farmer-facing tool that connects legume growers with buyers, shows whether growing legumes pays off on their farm, and lets the farmer choose which data goes to which buyer.

Status: early draft. See `docs/` once added.

## Rules for this repo (hackathon)

- Never commit raw hackathon data (ToS 10.3). Only synthetic demo data or derived aggregates.
- Declare third-party libraries and AI use in `DECLARATIONS.md`.
- No code or packages from other projects (for example `@vbel/*`).
